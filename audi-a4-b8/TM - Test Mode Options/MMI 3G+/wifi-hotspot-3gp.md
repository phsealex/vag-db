## MMI 3G+ WIFI streaming
> You must have the [hidden menu](/audi-a4-b8/5F%20-%20Electrical%20Information/10%20-%20Adaptation.md#hidden-menu) enabled.

- Enter the Hidden Menu
- Go to `/diagnose/settings/wlan_settings`
- Set `WLAN activation` to TRUE (check it)
- Go to `/diagnose/settings/ami_aux`
- Select `AUX [enabled] 1/2`
- Restart your MMI
