# Seatbelt Chime
### Byte 0
![Bit 2 & 4](/common/svg/bitSelectBits24.svg)

Set **bits 2 - 4** to disable seatbelt chime.

# Needle Sweep / Gauge Needle Test
### Byte 1
![Bit 0](/common/svg/bitSelectBit0.svg)

Set **Bit 0** to enable needle sweep, unset to disable.

# Lap Timer/Oil Temp display
### Byte 3

![Bit 3](/common/svg/bitSelectBit3.svg)

Set **Bit 3** to enable the Lap Timer, unset to disable it.
